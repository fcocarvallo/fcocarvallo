## Projects and Work

### ⛏️ Lode · Founder & Developer (Oct 2026 – present)
Open source learning platform for mining economics, in development. *Repository private for now; it will be published here.*
- App for iOS, Android and Web built in Flutter, where users pick a mining project, change one decision and instantly see how reserves and value change.
- On-device engine that runs the full chain: resource → break-even cut-off → reserve → production plan → cash flow → NPV, checked against the technical report and automated tests.
- Interactive simulations of mining processes, including a flotation cell and a simple-kriging drill-section model for resource estimation, plus a map of 26 U.S. deposits.
- Roadmap: AI extraction of figures from S-K 1300 / NI 43-101 reports (Python, FastAPI, PostgreSQL/PostGIS) and ML for kriging and pit optimization.
